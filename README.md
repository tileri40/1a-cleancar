# Website 1a Clean Car

Statische Website für 1a Clean Car, Autoaufbereitung in Walldorf (www.1a-cleancar.de).

## Aufbau
- `build/build.py`: erzeugt alle Seiten. Firmendaten (Öffnungszeiten, Preise, Impressum) stehen oben im Block `FIRMA`.
- `assets/style.css`: Design
- `img/`: Bilder (WebP) und Video

## Ändern
1. Werte in `build/build.py` anpassen
2. `python3 build/build.py` ausführen
3. Änderungen committen und pushen; GitHub Pages veröffentlicht automatisch.

Gelb markierte Stellen auf der Website sind Platzhalter, die noch ausgefüllt werden müssen.
